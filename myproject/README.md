# Интернет-магазин (учебный проект)

Этот проект создан в рамках изучения курса по веб-разработке на Python. 
На данный момент реализован базовый функционал сайта: главная страница и страница с контактной информацией.

## Используемые технологии:
- **Python** (3.14)
- **Django** (фреймворк)
- **Bootstrap 5**

## Реализованный функционал:
- Главная страница с приветственным текстом.
- Страница контактов с формой обратной связи.
- Обработка GET и POST-запросов на стороне сервера.

## Как запустить проект локально:
1. Клонируйте репозиторий на свой компьютер.
2. Создайте и активируйте виртуальное окружение.
3. Установите зависимости: requirements.txt
4. Запустите сервер разработки.
5. Перейдите в браузере по адресу: http://127.0.0.1:8000/catalog/
